# Agents: everything lives in `vid-gen/`

Josh's view of this folder is two things: `Final videos/` (finished MP4s only) and `vid-gen/` (all our work).
Read `vid-gen/CLAUDE.md` (the rules) and the top of `vid-gen/HANDOFF.md` before doing anything, and run every
command from inside `vid-gen/`. Never put anything else at the top level. Only finished, approved videos go in
`Final videos/` (make.mjs copies them there after a full render).
