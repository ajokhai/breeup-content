# H1 Homepage hero loop

Silent background loop for the homepage hero (website agent's spec in HANDOFF, 2026-10-04): no text, captions,
logo or UI; subject and motion in the upper/right; bottom 40% calm; 12-16 s seamless loop; 16:9 + 9:16;
no audio; H.264, about 3-5 MB.

Made from one Veo clip per shape (from an approved still in `media/generated/H1/`), slowed to ~13 s with
motion interpolation, and cross-dissolved end-into-start so it loops seamlessly. Built by `build.sh`.
