# BreeUp style guide (living)

Rewritten by `node tools/gemini.mjs learn` each time a reference is studied. Seeded 2026-10-03 from the T1 review.

- Transitions: crisp directional wipes, whip pans, push and light-leak cuts. No expanding-circle or PowerPoint-style
  shape wipes (T1 review: "looks cheap").
- Generated people never face a screen toward camera: show the back of the phone. Real UI comes from screenshots.
- Every shot must show the action the shot list needs (phone in hand, code being checked), not just mood.
- Gold ring highlight on the exact control and large 9:16 type both work well. Keep them.
